## 🔧 技术实现

### 1. 地址数据结构
```python
{
    "name": "组织名称",
    "type": "residential|student|school|office",
    "line1": "详细街道地址",
    "line2": "",
    "city": "城市名",
    "state": "州/省",
    "postal_code": "邮编",
    "country": "国家代码"
}
```

### 2. 优化功能
- **优先城市匹配**: `_pick()` 函数支持 `preferred_city` 参数，优先返回指定城市的地址
- **类型多样性**: 每个国家包含住宅、学生宿舍、学校、企业办公室等多种类型
- **真实性**: 所有地址基于真实公共机构（大学、知名企业总部等）

### 3. API 接口
- `GET /api/manage/builtin-addresses` - 获取全局统计
- `GET /api/manage/builtin-addresses?country=XX` - 按国家筛选
- `GET /api/manage/builtin-addresses?type=YY` - 按类型筛选
- 支持分页：`limit` 和 `offset` 参数

## 🐛 修复问题

### 问题1: .env 文件加载失败
**现象**: 应用启动时无法加载环境变量
**原因**: `load_dotenv()` 未指定绝对路径，后台进程工作目录不一致
**解决**: 修改为 `load_dotenv(ROOT / ".env")`

### 问题2: 多进程监听端口冲突
**现象**: 登录请求被旧进程处理，导致认证失败
**原因**: 多次启动应用导致多个进程同时监听 18082 端口
**解决**: 使用 `netstat` 和 `taskkill` 清理所有旧进程
